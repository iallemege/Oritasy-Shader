# Oritasy's Shader 0.1

Lighting, sky, weather and the two clocks for Nuclear Option. Unzip into `BepInEx/plugins`. Press F2. Drag the title bar to move the window, and the bottom-right corner to resize it.

The clock speed is how fast the sun moves, from 0.001× the mission's own speed up to 16×. Slow motion is separate: it runs the match itself from 0.001× to 1×. On the host that slows the whole match. On anyone else it slows only that machine.

The sky needs `OritasyShader/fx.bundle` next to the other plugins.
